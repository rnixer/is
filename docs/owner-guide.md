# คู่มือร้าน igh.ess

ระบบนี้เริ่มในโหมดทดสอบ สินค้าจาก Instagram ช่วง 1 กรกฎาคม–5 ตุลาคม 2026 อยู่ใน Strapi เป็นฉบับร่างทั้งหมด ยังไม่เปิดรับชำระเงิน ข้อมูลที่พบ: 163 รายการ / 170 รูป มี 93 caption ระบุ SOLD ชัดเจน จึงตั้ง SKU ของรายการเหล่านี้เป็นสต็อก 0 ส่วนรายการอื่นมีจำนวนตั้งต้น 1 แต่ปิดการขายไว้จนกว่าจะตรวจสอบ

## เข้าจัดการสินค้า

เปิด http://localhost:1337/admin แล้วสร้างบัญชีผู้ดูแลครั้งแรกเอง รหัสผ่านไม่ได้ถูกตั้งหรือบันทึกใน Git

ไป Content Manager → Product เพื่อดูรายการทั้งหมด ตรวจรูป ชื่อ ขนาด เนื้อผ้า และราคา `priceSatang` (200 บาท = 20000) รายการไหนขายไปแล้วลบหรือเก็บเป็น draft ได้ การลบ Product จะทำให้หน้าเว็บไม่แสดงรายการนั้น ส่วน SKU ที่ไม่มีสินค้าเผยแพร่จะซื้อไม่ได้

สำหรับสินค้าที่ยังมีอยู่:

1. ตรวจราคา/ข้อมูล Product แล้วตั้ง `reviewState` เป็น `APPROVED` และ Save
2. ไป Variant หา SKU เดียวกัน ตรวจ `productSlug` ให้ตรงกับ Product ตั้ง `stock` เป็น 1 และ `active` เป็น true
3. กลับ Product แล้ว Publish ระบบจะตรวจว่าผ่านการตรวจสอบและมี SKU ตรงกันก่อน
4. ก่อนตรวจหน้าเว็บสำหรับลูกค้าให้ตั้ง `PREVIEW_DRAFTS=false` ใน `apps/storefront/.env` แล้วเริ่ม frontend ใหม่

สินค้าแต่ละชิ้นมีเพียงตัวเดียว ไม่มีการเลือก S/M/L ที่สร้างขึ้นเอง ใช้ขนาดเสื้อจริงตาม caption ระบบกันการสั่งชิ้นเดียวกันพร้อมกัน และลดสต็อกเมื่อ Stripe ยืนยันว่าจ่ายสำเร็จแล้ว สินค้าที่กำลังจองชำระเงินจะไม่ให้แก้สต็อกจนกว่าจะจ่ายหรือหมดเวลา

## สินค้าใหม่

สร้าง Product ใน Strapi กรอก SKU ที่ไม่ซ้ำ ชื่อ slug ราคา ขนาด เนื้อผ้า หมวดหมู่ และอัปโหลด/เรียงภาพ สร้าง Variant โดยใช้ SKU และ productSlug ให้ตรงกับสินค้า สต็อก 1 และ active=true ตรวจข้อมูลแล้ว APPROVED → Publish ไม่ต้องแก้โค้ดหรือใช้ Instagram API

## ออเดอร์

ไป Content Manager → Order สถานะการชำระเงินมาจาก webhook เท่านั้น ข้อมูลสินค้าราคาและที่อยู่ถูกเก็บเป็น snapshot จึงไม่เปลี่ยนตามการแก้สินค้า แก้ได้เฉพาะ `fulfillmentStatus` และ `trackingNumber` เมื่อจัดของหรือส่งแล้ว ห้ามแก้ paymentStatus ให้ paid เอง

`PAYMENT_REVIEW` หมายถึงต้องตรวจ Stripe ก่อนดำเนินการ เช่น มีเงินเข้าหลังการจองถูกปล่อยไปแล้ว ห้ามส่งสินค้าที่ไม่มีอยู่หรือรับเงินซ้ำ ให้ตรวจรายการจริงและคืนเงินเมื่อเหมาะสมผ่าน Stripe

## กติกาที่ใช้

- ประเทศไทยเท่านั้น / บาทไทย
- ค่าส่ง 30 บาทต่อออเดอร์ ไม่ใช่ต่อชิ้น ระบบคิดฝั่ง backend
- นโยบายร้านไม่รับเปลี่ยน/คืนตามที่ยืนยันไว้ ติดต่อร้านเมื่อมีปัญหาสินค้าหรือออเดอร์
- หน้าเว็บแสดงช่องทาง Instagram และ LINE จาก caption ร้านเดิม
- ระยะเวลาจัดส่งและบริษัทขนส่งยังไม่ได้ระบุ จึงไม่ได้สร้างข้อมูลขึ้นเอง
